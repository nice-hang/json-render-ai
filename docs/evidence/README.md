# 验证证据

本目录保存用于关闭阶段的简洁、可复现证据。优先记录文本，不提交大型生成物。

文件使用日期命名：

```text
YYYY-MM-DD-phase-<编号>-verification.md
```

不属于单一阶段退出门的交付级证据可使用 `YYYY-MM-DD-<主题>-verification.md`，例如本地私有交付包复验。

应记录：

- Commit 或工作树固定点
- 环境和相关版本
- 实际执行的命令及退出状态
- 人工复现步骤和观察结果
- 必要的浏览器或部署地址检查
- 已知限制和未执行检查
- 能实质证明验收标准的截图或报告链接

不得提交凭据、签名 URL、私人用户数据或包含敏感信息的原始日志。
