# 阶段 5：比赛交付

- 状态：`in_progress`
- 权威规格：[`../specs/2026-09-02-webmcp-builder-mvp.md`](../specs/2026-09-02-webmcp-builder-mvp.md)
- 依赖：Stage 4 `verified`；用户授权部署及任何外部发布操作
- 目标结果：形成可公开访问、可复现、材料完整并已逐项核对官方要求的比赛 MVP 提交包。

## 范围

- 干净 clone 复现、依赖/许可证/秘密扫描和生产构建。
- 生产 HTTPS 部署及无登录新会话验证。
- 完成英文 README、架构图、演示步骤、限制和许可证。
- 录制 2–3 分钟视频，准备截图、短/长描述和最终 AC 追踪表。
- 在提交当天依据官方来源逐项核对规则；实际提交需用户最终确认。

## 非目标

- 不临时增加功能或重构架构。
- 不在用户授权前部署、推送、公开视频或提交比赛。
- 不将本规划中的假设当作官方规则。

## 任务

- [x] **5.1 从干净环境验证仓库制品**
      Spec ref: `MVP 规格 > AC-01、AC-15、AC-17`
      What to build: 在临时目录按 README clone/install/test/build；检查锁文件、许可证、敏感信息和本地路径。
      Acceptance: 10 分钟内完成；所有门禁退出码 0；secret scan 无真实凭据；README 命令逐字可执行。
      Verify: `pnpm install --frozen-lockfile && pnpm lint && pnpm typecheck && pnpm test && pnpm test:e2e && pnpm build`

- [x] **5.2 部署并验证生产环境**
      Spec ref: `MVP 规格 > AC-16`
      What to build: 生成生产部署并记录固定 URL、部署提交和环境要求。
      Acceptance: HTTPS、无登录新会话可开；CRM 重置、8 工具发现、Agent 修改、确认和撤销均通过；无致命控制台错误。
      Verify: 对生产 URL 运行 `pnpm test:e2e:production` 和人工新会话检查。

- [ ] **5.3 完成公开文档和提交素材**
      Spec ref: `MVP 规格 > AC-17、AC-18`
      What to build: README、架构说明、2–3 分钟视频、至少 3 张截图、项目短/长描述、运行和限制说明。
      Acceptance: 视频展示真实 WebMCP 与完整 wow moment；链接公开可访问；截图不含敏感数据；描述不声称未实现能力。
      Verify: 逐一打开仓库、URL、视频和图片链接；由非开发环境复核。

- [ ] **5.4 关闭 AC 追踪与官方规则核对**
      Spec ref: `MVP 规格 > AC-01～AC-18`
      What to build: 生成 AC-01～AC-18 到具体证据的矩阵，并记录官方要求来源、核对日期、状态和负责人。
      Acceptance: 18/18 AC 均为 passed；官方 checklist 无 unknown/blocked；未运行项不能标绿。
      Verify: 审查 `docs/evidence/*`、最终追踪矩阵和官方 checklist。

- [ ] **5.5 准备最终提交交接**
      Spec ref: `MVP 规格 > AC-18`
      What to build: 汇总最终标题、描述、成员、仓库、生产 URL、视频、截图、技术说明和已知限制，等待用户确认。
      Acceptance: 所有字段与公开制品一致；用户看到最终将提交内容；只有收到明确确认后才执行实际提交。
      Verify: 人工逐字段预览并记录最终确认；提交后再单独验证公开项目页。

## 严格退出门

- [ ] AC-01～AC-18 最终追踪表为 18/18 `passed`，每项有可访问证据。
- [ ] 干净 clone、全量测试和生产构建全部退出码为 0。
- [ ] 生产环境完整演示至少 2 次成功，包含真实 WebMCP 工具调用。
- [ ] README、许可证、生产 URL、视频和至少 3 张截图均公开可访问。
- [ ] 官方规则 checklist 在提交当天复核，无 `unknown`、`failed` 或未接受 blocker。
- [ ] 仓库与素材无凭据、私人数据、本地绝对路径或虚假能力声明。
- [ ] 用户完成最终人工审阅并明确确认提交；提交动作及结果另行验证。

只有以上全部通过，项目才可以声明“比赛 MVP 可交付”。部署完成但素材不全、测试全绿但真实 WebMCP 未验证、或视频完成但生产地址不可用，都不满足退出门。

## 回滚或降级

生产发布失败时保留最后一个已验证部署并停止提交；规则存在 blocker 时不做规避性声明。任何外部提交错误都先保存当前材料和公开链接，取得用户方向后再修改。

## 最终交接

- 已交付：可复现仓库、生产应用、演示视频、截图、提交文案和完整证据。
- 遗留风险：仅保留已在提交材料中透明披露且不阻塞官方要求的限制。
- 下一道门：用户最终确认并执行比赛提交。
